# shopnest-mern-ecommerce
MERN stack e-commerce project

ShopNest is a full-stack e-commerce web application built using the MERN stack (MongoDB, Express.js, React.js, Node.js).
It provides a complete online shopping experience with authentication, cart system, payments, and admin dashboard.

Tech Stack
Frontend: React.js, Redux Toolkit, React Router
Backend: Node.js, Express.js
Database: MongoDB with Mongoose
Authentication: JWT (JSON Web Token)
Payment Gateway: Razorpay
Other Tools: Cloudinary (image upload), bcryptjs, Nodemailer

Features
User Registration & Login (JWT Authentication)
Product browsing and search
Add to Cart / Remove from Cart
Secure checkout with Razorpay payment
Order management system
Admin dashboard (Add/Edit/Delete products)
Image upload using Cloudinary
Email notifications

How to Run This Project
1️⃣ Clone Repository
git clone https://github.com/Tanmay1145/shopnest-mern-ecommerce.git

2️⃣ Backend Setup
cd backend
npm install
node server.js

3️⃣ Frontend Setup
cd frontend
npm install
npm start
